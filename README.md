# trading_bot
In this repository, I showcase some trading bots that I have developed myself.

## Backtests

The [`backtests/`](backtests/) folder has a Dukascopy data downloader and a robustness
test suite (costs, random-entry benchmark, Monte Carlo, parameter sensitivity,
walk-forward). Results for the bots evaluated so far are in
[`backtests/reports/RESUMEN.md`](backtests/reports/RESUMEN.md) (in Spanish).

Demo-ready `.mq4` variants from the improvement study are in [`demo/`](demo/)
(not compiled yet: compile and check them in MetaTrader before use).
